Key terms, defined

Every important word in the project, in one or two plain sentences. Learn these first. If you can define a term simply, you understand it.

In plain words

Examiners often start with "What is…?" questions. A short, exact definition shows you are in control. A long, wandering one suggests you are not. Each definition below is written so you can say it out loud in under fifteen seconds.

Gas and sensors

Gas leak
Unwanted escape of gas from a pipe, tank, valve or cylinder into the air around it.
LEL (Lower Explosive Limit)
The smallest gas concentration in air that can catch fire. For methane it is about 5% by volume.
IDLH
"Immediately Dangerous to Life or Health": the concentration that can kill or cause lasting harm quickly. Ammonia: 300 ppm.
ppm
Parts per million. 100 ppm means 100 gas molecules in every million molecules of air.
MOS sensor (metal-oxide semiconductor)
A heated metal-oxide film (often SnO₂) whose electrical resistance falls when certain gases touch it. Cheap and fast, but not very selective.
MQ sensors
A family of low-cost MOS sensor modules. Each is tuned to a target gas: MQ2 LPG/smoke, MQ3 alcohol, MQ5 natural gas, MQ6 LPG, MQ7 CO, MQ8 hydrogen, MQ135 air quality.
Cross-sensitivity
A sensor reacting to gases other than its target. It is why one sensor cannot identify a gas, but an array can.
Sensor array / electronic nose
Several partly selective sensors read together. Their combined pattern acts as a fingerprint of the gas.
ADC (analog-to-digital converter)
Turns the sensor's voltage into a number. A 10-bit ADC gives integers from 0 to 1023, which is what the dataset contains.
Sensor drift
Slow change of a sensor's output over time for the same gas, caused by ageing, heat, humidity or contamination.
Threshold alarm
An alarm that rings when one sensor's reading passes a fixed value. Simple, but blind to which gas is present.

Machine learning basics

Feature x
One input number. Here each reading has 7 features, one per sensor, so a reading is a vector \(\mathbf{x}\in\mathbb{R}^7\).
Label / class y
The correct answer for a reading: NoGas, Perfume, Smoke or Mixture.
Classification
Learning a rule that maps a feature vector to a class.
Supervised learning
Learning from examples whose correct labels are already known.
Training / validation / test set
Training data fits the model; validation data checks it during development; test data is used once, at the end, to measure honest performance. Here: 70% / 15% / 15%.
Stratified split
A split that keeps the class proportions the same in every part (here 1:1:1:1).
Standardisation (z-score)
Rescaling each feature to mean 0 and standard deviation 1: \(z=(x-\mu)/\sigma\). It stops large-valued sensors from dominating.
Overfitting / underfitting
Overfitting: the model memorises training data and fails on new data. Underfitting: the model is too simple to capture the pattern.
Hyper-parameter
A setting chosen before training rather than learned, such as \(C\) and \(\gamma\).
PCA (principal component analysis)
Finds the directions in which the data varies most (eigenvectors of the covariance matrix). Used here only to draw the 7-D data in 2-D.

Support Vector Machine

Support Vector Machine (SVM)
A classifier that separates two classes with the boundary that leaves the widest possible empty gap between them.
Hyperplane wᵀx + b = 0
A flat boundary: a line in 2-D, a plane in 3-D, and its 7-D equivalent here. \(\mathbf{w}\) sets its direction, \(b\) its position.
Margin 2/‖w‖
The width of the empty band around the boundary. The SVM makes it as wide as possible.
Support vectors
The training points on or inside the margin. They alone decide the boundary; all other points could be deleted without changing it.
Hard margin
An SVM that allows no point inside the margin. Only possible when the classes separate perfectly.
Soft margin / slack ξᵢ
Allows some points inside the margin or on the wrong side. \(\xi_i\) measures how far point \(i\) breaks the rule.
Regularisation parameter C
The price of breaking the margin. Large \(C\): few mistakes allowed, narrow margin. Small \(C\): wide margin, more mistakes tolerated.
Hinge loss
\(\max\{0,\,1-y f(\mathbf{x})\}\): zero for points safely on the right side, growing linearly for points that break the margin.
Kernel K(x, z)
A function that measures similarity between two readings and acts like an inner product in a hidden, higher-dimensional space.
Kernel trick
Getting a curved boundary by using a kernel, without ever computing the high-dimensional coordinates.
RBF (Gaussian) kernel exp(−γ‖x−z‖²)
Similarity that is 1 for identical readings and fades to 0 as they move apart.
Gamma γ
How fast RBF similarity fades. Large \(\gamma\): each point influences only its close neighbours (wiggly boundary). Small \(\gamma\): smooth boundary.
One-vs-one (OvO)
Splits a 4-class problem into 6 two-class SVMs, one per pair. Each votes; the class with most votes wins.
Decision function f(x)
\(f(\mathbf{x})=\sum \alpha_i y_i K(\mathbf{x}_i,\mathbf{x})+b\). Its sign gives the class; its size is a confidence score.
Platt scaling
Fits a sigmoid to SVM scores to turn them into probabilities.

Optimisation

Convex problem
A problem with a bowl-shaped objective and constraints, so any local minimum is the global minimum. Training an SVM is convex.
Quadratic programme (QP)
Minimising a quadratic function under linear constraints. Both SVM forms (primal and dual) are QPs.
Primal problem
The original SVM problem written in terms of \(\mathbf{w}\), \(b\) and \(\xi\).
Lagrange multiplier αᵢ
A weight attached to each constraint. In the SVM, \(\alpha_i>0\) exactly for support vectors.
Lagrangian 𝓛
The objective plus each constraint multiplied by its multiplier. Setting its derivatives to zero links primal and dual.
Dual problem
An equivalent problem written in terms of the multipliers \(\alpha_i\) only. Data appear only through kernel values, which allows the kernel trick.
KKT conditions
Karush–Kuhn–Tucker conditions: the checklist an optimal solution must satisfy. For convex problems they are both necessary and sufficient.
Complementary slackness
For each constraint, either its multiplier is zero or the constraint is exactly tight. This is why only boundary points become support vectors.
Mercer's theorem
A function is a valid kernel exactly when it is symmetric and positive semi-definite. This keeps the dual convex.
SMO (sequential minimal optimisation)
The algorithm LIBSVM uses: it repeatedly solves the dual for just two multipliers at a time, which can be done exactly.

Evaluation

Accuracy
Fraction of predictions that are correct.
Confusion matrix
A table of true class (rows) against predicted class (columns). The diagonal is correct; everything else is an error.
Precision
Of the readings the model called class \(p\), how many really were \(p\). "Can I trust this alarm?"
Recall / sensitivity
Of the readings that really were class \(p\), how many the model found. "Did we miss any leaks?"
Specificity
Of the clean-air readings, how many were correctly passed as clean.
F1-score
The harmonic mean of precision and recall. High only when both are high.
Macro average
The plain average of a metric over the classes, so every class counts equally.
ROC curve and AUC
The ROC curve plots true positive rate against false positive rate for every threshold. AUC is the area under it: 1 is perfect, 0.5 is guessing.
False alarm rate
Fraction of clean-air readings wrongly flagged as gas: \(FP/(FP+TN)\).
k-fold cross-validation
Split training data into \(k\) parts; train on \(k-1\), test on the remaining one, rotate, and average. Gives a stable score for choosing settings.
Grid search
Trying every combination from a list of hyper-parameter values and keeping the best cross-validation score.
Learning curve
Accuracy plotted against training-set size. Shows whether more data would help.
Chronological (time-ordered) split
Train on earlier readings, test on later ones. A tougher, more realistic test than a random split.

Real-time and deployment

Real-time system
A system that is only correct if it answers before a deadline. Here the deadline is the next reading, 2 seconds later.
Latency
The time from receiving one reading to giving its prediction. Measured here: about 1.1 ms.
Inference
Using a trained model to predict. Training is done once offline; inference happens for every reading.
IoT (Internet of Things)
Small connected devices (sensors, microcontrollers) that measure and report data over a network.
Edge / TinyML
Running the model on the small device itself rather than in the cloud. Faster and works without internet.
Microcontroller (e.g. ESP32)
A tiny, cheap computer on one chip that reads sensors and can run a small model.
