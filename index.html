The whole idea of a Support Vector Machine in one picture. Teal circles are one class, orange squares the other. The solid line separates them; the dashed lines mark the margin, the empty gap on each side. The SVM picks the line with the widest gap. The circled points touch the margin: they are the support vectors, and only they decide where the line goes.

In plain words — what you actually did

Factories, warehouses and cold stores use gases such as LPG and ammonia. Leaks kill people. Most cheap gas alarms just watch one sensor and ring when it passes a fixed level. That alarm cannot tell a dangerous leak from a harmless smell like perfume, so it gives false alarms and people learn to ignore it.

You used seven cheap gas sensors at once. Each sensor reacts a little differently to each gas, so together they give a pattern, like a fingerprint. You then trained a Support Vector Machine (SVM) to read that fingerprint and say which of four situations it is: no gas, perfume, smoke, or a mixture.

A plain straight-line SVM got 80.31% right. After putting all sensors on the same scale and choosing two settings carefully, the curved (RBF) SVM got 98.23% right on readings it had never seen. It decides in about 1 millisecond, while a new reading arrives only every 2 seconds. So it is fast enough for real-time use.

The project in one paragraph

Using the public MultimodalGasData set (6,400 readings from 7 MQ metal-oxide sensors, 4 balanced classes), you derived the soft-margin SVM from first principles (margin, Lagrangian dual, KKT conditions, RBF kernel, one-vs-one voting), then trained it. Standardisation plus a 5-fold cross-validated grid search chose \(C = 100\) and \(\gamma = 10\). The model reached 98.23% test accuracy, macro F1 0.9823, macro ROC-AUC 0.9986, 99.03% leak sensitivity and about 1.1 ms per prediction. A time-ordered test then showed the main limit honestly: sensor drift.

Where you actually stand

This is an applied mathematics + machine learning project on a public laboratory dataset. You did not build hardware and the gases are deodorant and incense smoke, not LPG or ammonia. Say this early and calmly. The method is the contribution; the data is the test bed. Page 11 prepares you for exactly these questions.
