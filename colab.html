Run it in Google Colab, in your browser

Colab is a free notebook from Google. There is nothing to install: you open a web page, load the project, and run the same thirteen scripts one cell at a time. It is the easiest way to show the work to other people, because the finished notebook, with all its results and figures, can be shared with one link.

Tested on Colab

All twelve steps were run in a real Colab notebook (Python 3.13, scikit-learn 1.6.1, pandas 2.2.3). Every accuracy figure matched the report and the laptop run exactly: 98.23% test accuracy, C = 100, γ = 10, 1,304 support vectors, 54.37% on the drift test. Only timings differ. Colab updates its libraries from time to time, and the numbers stay the same. Step 12, the pipeline case study, was added later and was tested on the laptop (Python 3.12), not yet on Colab.

In plain words

A Colab notebook is a document made of cells. You put a command in a cell, press the ▶ button (or Shift+Enter), and the answer appears right under it. The computer that does the work belongs to Google, so even an old laptop is fast enough. Because the answers are saved inside the notebook, anyone you send it to sees them without running anything.

Lines that start with ! are run as terminal commands. Here, !python 05_tune_rbf_svm.py means “run script 05”. It is the same command as on the VS Code page.

A · Set up the notebook (about 3 minutes)

  1. Open a new notebook

    Go to colab.research.google.com, sign in with a Google account, and choose New notebook. Leave the runtime on its default (CPU). A GPU does not help an SVM. You will see one empty code cell.

  2. Cell 1 — bring the project into Colab

    First, on your own computer, zip the svm_gas_code folder (Windows: right-click the folder → Send to → Compressed (zipped) folder; Mac: right-click → Compress). You get svm_gas_code.zip.

    In Colab, click the folder icon in the left bar, then the upload icon (the arrow pointing up), and choose the zip. Wait until the little progress circle disappears. Then click into the first cell, paste this, and press Shift+Enter: 

    !unzip -q -o svm_gas_code.zip
%cd /content/svm_gas_code
!ls

    It unpacks the zip, moves into the folder, and lists it. The first line of output is /content/svm_gas_code, followed by the files 00_check_setup.py to run_all.py, common.py, data and the rest.

    Uploaded files disappear when the Colab session ends, so repeat this cell next time.

  3. Cell 2 — check the setup

    Click + Code to add a new cell, then:

    !python 00_check_setup.py
    You should see (versions change over time) 
    Python  : 3.13.16 at /usr/bin/python3
numpy      : 2.1.3
pandas     : 2.2.3

    Do not run pip install -r requirements.txt here

    Colab already has every library. Installing over them can force a session restart and gains nothing.

Want fewer cells?

Cells can hold several lines. Putting steps 01 to 04 in one cell, and steps 06 to 12 in another, works fine. For a quick demo, one cell with !python run_all.py --quick runs the whole sequence with smaller grids, with the same final numbers. Steps 00 to 11 took about 2½ minutes on Colab (tested); step 12 adds about a minute more.

C · See the figures inside the notebook

Scripts save their figures as files. To show one under a cell, paste this and change the file name: 

from IPython.display import Image, display
display(Image("outputs/figures/fig_confusion_improved.png", width=500))

You see the confusion matrix with 230, 10, 7 and 233 on the top two rows. To show every figure in one go: 

import glob
for path in sorted(glob.glob("outputs/figures/*.png")):
    print(path)
    display(Image(path, width=600))

There are 22 figures, so this one is long. You can also open the folder icon on the left, go to svm_gas_code → outputs → figures, and double-click any picture.

D · Share the finished notebook

  1. Run every cell first

    The results are saved inside the notebook, so people who open it see your outputs and figures straight away. Colab saves automatically to your Google Drive. Name it (click “Untitled0” at the top), for example Gas Leak SVM — project demo.

  2. Add short headings (optional, but it helps a panel)

    Click + Text between cells and write a one-line title such as “Step 5: tune the RBF-SVM (98.23%)”. Then open View → Table of contents to show the structure.

  3. Press Share and choose “Anyone with the link”

    Click Share (top right), change General access from “Restricted” to Anyone with the link, keep the role as Viewer, and copy the link. Viewers can read everything but cannot change your notebook.

  4. If others want to run it themselves

    They open the link, choose File → Save a copy in Drive, then Runtime → Run all. Cell 1 downloads the project for them, so they need nothing from you. Running everything takes about 7 minutes.

Colab forgets the files, not the results

If the notebook sits idle for a while, Colab disconnects and deletes the unpacked folder and the saved model. The printed outputs stay in the notebook. To run again, reconnect and re-run Cell 1 and then step 05 before any later step.

E · If something breaks

You seeWhat it means and how to fix it
python3: can't open file '…/00_check_setup.py' You are not inside the project folder. Run %cd /content/svm_gas_code, then try again. This happens after the runtime restarts.
unzip: cannot find or open svm_gas_code.zip The upload has not finished, or the zip has another name. Check the file list in the left bar.
The tuned model does not exist yet The model is created by step 05. Run it first, or again if the runtime was reset.
Everything has vanished after a break The runtime was recycled. Re-run Cell 1, then step 05, then whatever you need.
Step 05 takes long Free Colab has two CPU cores, so allow about two minutes. Or use !python 05_tune_rbf_svm.py --quick.
The cell shows a spinner for a long time Steps 05, 06 and 07 are slow by nature. A ✓ next to the cell with a time means it finished.
