Python lab — train the SVM here

Real Python and real scikit-learn, running inside this page. No install, no account. Every cell is editable: change a number, press Run, and see what happens. The cells reproduce the report's numbers from the same data.

How it works · Python not started

The first Run downloads Pyodide (Python compiled for the browser) plus scikit-learn, about 20–30 seconds. After that it is quick. All cells share one Python, and Cells 1 and 2 load and split the data — run them first. Ctrl+Enter runs the cell you are typing in. Training is slower in a browser than on a laptop, so allow a few seconds per model.

In plain words

The report says "98.23%". This page lets you show it. In a viva, running the model live in front of the panel is far more convincing than reading a number from a table.

It also links the code to the mathematics. Cell 7 takes the trained SVM apart: it pulls out the support vectors and the \(\alpha_iy_i\) weights, computes the decision function \(f(\mathbf{x})=\sum\alpha_iy_iK(\mathbf{x}_i,\mathbf{x})+b\) by hand, and shows it equals scikit-learn's answer. That is Eq. (3.23) of your report, working.
