Run it in VS Code, step by step

The whole experiment is split into twelve small scripts. You run them one at a time and watch each result appear, in the same order as the report. It works on Windows, macOS and Linux, and the only things you install are Python and a few libraries.

No install?Use Google Colab Same scripts in the browser, on page 15

Tested, not guessed

Every step on this page was run from a fresh virtual environment on a Windows 10 computer, from a folder whose path contains spaces: the full run with Python 3.14, and the quick run (section C) with Python 3.12. The outputs shown are copied from those runs. The accuracy numbers were identical in both and on Google Colab too; only the timings change. The macOS and Linux commands are the standard equivalents. I could not test those on a Mac here.

In plain words

Think of the folder as a small kitchen. Python is the stove, the libraries (scikit-learn, pandas, matplotlib) are the pots, and the virtual environment is a private cupboard that holds only the pots this project needs, so nothing else on your computer is touched. Each numbered script is one recipe step: load the data, split it, train, evaluate.

Everything uses seed 42, so your numbers will match the report exactly: 98.23% test accuracy for the tuned RBF-SVM.

A · One-time setup (about 10 minutes)

  1. Install Python 3.9 or newer

    Download it from python.org/downloads. On Windows, tick “Add python.exe to PATH” on the first installer screen, then press Install Now. Missing that tick is the most common reason nothing works later.

    On Linux, Python is usually already there: sudo apt install python3 python3-venv python3-pip adds anything missing. Check it:

    Windows (PowerShell) 
    py --version
    macOS / Linux (Terminal) 
    python3 --version

    It should print something like Python 3.12.10.

  2. Install VS Code and its Python extension

    Get VS Code from code.visualstudio.com. Open it, press Ctrl+Shift+X (Mac: Cmd+Shift+X), search for Python, and install the one published by Microsoft.

  3. Get the project folder

    You need the svm_gas_code folder (the scripts plus the data folder). If you are working on your own computer, it is already there. To move it to another computer, zip the folder (Windows: right-click the folder → Send to → Compressed (zipped) folder; Mac: right-click → Compress) and copy the zip across. On the new computer, extract it (Windows: right-click → Extract All; Mac: double-click) and put the svm_gas_code folder somewhere easy, such as Documents. Do not run anything from inside the zip.

    Inside you should see:

    svm_gas_code/
  data/                         the sensor CSV and four thermal images
  00_check_setup.py  ...  11_make_illustrations.py
  common.py   run_all.py   all_in_one_svm_gas_experiment.py
  requirements.txt   README.md

  4. Open the folder in VS Code

    File → Open Folder…, choose svm_gas_code, and click “Yes, I trust the authors” if asked. The Explorer panel on the left now lists the files. Open the folder itself, not a single file. The scripts find the data by their own location, so this keeps everything working.

  5. Open a terminal inside VS Code

    Terminal → New Terminal (or Ctrl+`). A panel opens at the bottom, and its prompt should end with svm_gas_code. Every command below is typed there, one at a time, followed by Enter.

  6. Create the virtual environment

    This makes a hidden folder called .venv inside the project.

    Windows (PowerShell) 
    py -m venv .venv
    macOS / Linux 
    python3 -m venv .venv

    If VS Code pops up “We noticed a new environment has been created. Do you want to select it?”, click Yes.

  7. Switch the environment on

    Windows (PowerShell) 
    .venv\Scripts\Activate.ps1
    macOS / Linux 
    source .venv/bin/activate

    The prompt now starts with (.venv). Check for it before every session. From here on, python means the project's Python on every system.

    Windows says “running scripts is disabled on this system”?

    Run this once, then activate again: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned and answer Y. Or open a Command Prompt terminal instead and use .venv\Scripts\activate.bat.

  8. Tell VS Code which Python to use

    Press Ctrl+Shift+P (Mac: Cmd+Shift+P), type Python: Select Interpreter, and pick the entry that mentions .venv. The bottom-right corner of VS Code then shows it. This only matters for the ▶ Run button; commands typed in the terminal use whatever is activated there.

  9. Install the libraries

    python -m pip install -r requirements.txt

    This downloads numpy, pandas, matplotlib, seaborn, scikit-learn and joblib. It needs internet and takes one to three minutes. It ends with a line starting Successfully installed.

  10. Check that everything is ready

    python 00_check_setup.py
    You should see (version numbers will differ on your computer) 
    Python  : 3.12.10 at C:\...\svm_gas_code\.venv\Scripts\python.exe
numpy      : 2.5.4
pandas     : 3.1.0
matplotlib : 3.11.2
seaborn    : 0.13.2
sklearn    : 1.9.1
joblib     : 1.6.0
Data    : found -> C:\...\svm_gas_code\data\Gas_Sensors_Measurements.csv

ALL GOOD. You can run 01_load_data.py next.

    If it says NOT READY, the message tells you what is missing. See section D.

B · Run the steps one by one

You can run a script two ways. Terminal: type the command shown. Button: open the file in VS Code and click the ▶ at the top right (“Run Python File”). Both give the same output. The scripts print their results in the terminal and save figures and tables into a new folder called outputs. Click any .png in the Explorer to view it inside VS Code.

Order matters for three scripts

Step 05 trains the main model and saves it. Steps 06, 08 and 09 load that saved model, so run 05 before them. The others do not depend on each other.

05The main model: tuned RBF-SVM

Scales the data, then tries 42 combinations of C and γ with 5-fold cross-validation (210 model fits), keeps the best, and saves it. Report Sections 3.6, 3.7 and 4.3.

This is the slow step: 2 to 4 minutes

It prints Fitting 5 folds for each of 42 candidates and then looks frozen. It is working. On an older or two-core computer it can take up to 10 minutes. In a hurry? Add --quick to try only 9 combinations in about 30 seconds (same best answer, a smaller heat map).

C · Run everything at once

When you have seen each step, one command runs all twelve in order and stops at the first error: 

python run_all.py

With full grids it takes about 10 to 15 minutes on a 4-core laptop. For a fast demo use the quick version: 

python run_all.py --quick

It takes about 5 minutes and gives the same final numbers. Quick mode only shrinks the C/γ grid in steps 05 and 07, so the grid-search heat map has fewer cells. The report's figure comes from the full run.

There is also all_in_one_svm_gas_experiment.py, which is the same experiment written as one long file, in case you prefer to read it top to bottom.

D · If something breaks

You seeWhat it means and how to fix it
python or py “is not recognized” Python is not installed, or was installed without the PATH tick. Reinstall it with “Add python.exe to PATH” ticked, then close and reopen VS Code.
“running scripts is disabled on this system” See the yellow box in step 7: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, or use Command Prompt.
ModuleNotFoundError: No module named 'sklearn' (or pandas, seaborn…) The environment is not active, or the libraries are not installed. Look for (.venv) at the start of the prompt, then run python -m pip install -r requirements.txt again.
Cannot find …Gas_Sensors_Measurements.csv The data folder is not next to the scripts. Re-extract the zip, or copy the whole folder again, and keep it together.
The tuned model does not exist yet Run 05_tune_rbf_svm.py first, then 06, 08 or 09.
Step 05 or 07 seems frozen It is working; it can take several minutes on an older computer. Or stop it with Ctrl+C and add --quick.
The ▶ button uses the wrong Python Ctrl+Shift+P → Python: Select Interpreter → choose the .venv one. Or just type the command in the terminal.
macOS says python: command not found Before activating the environment, use python3. After source .venv/bin/activate, python works.
Plots look slightly different in font Figures use Times New Roman when your computer has it and a similar serif font when it does not. The numbers are unaffected.

Start a new session later

You never repeat the setup. Open the folder in VS Code, open a terminal, activate the environment (step 7), check for (.venv), and run any script.
