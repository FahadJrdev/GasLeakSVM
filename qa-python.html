In plain words

The whole experiment is one Python script of about 250 lines. It loads a CSV with pandas, splits it, scales it, trains SVMs with scikit-learn, and saves figures with Matplotlib. Examiners usually ask three things: which library does the real work (LIBSVM, inside scikit-learn's SVC), how you avoided cheating (scaler fitted on training data only, inside a pipeline), and can you reproduce it (fixed seed 42 — and the lab does it live).

Tools

Which language and libraries did you use?

Python 3 with scikit-learn 1.9.1 for the SVM, NumPy and pandas for data, and Matplotlib and Seaborn for figures.

Y02

Did you implement the SVM yourself?

No — I derived it mathematically, but training uses scikit-learn's SVC, which wraps LIBSVM, a well-tested SMO-type solver; writing my own would add bugs, not insight.

I did check the implementation against the theory: the lab, Cell 7 recomputes \(f(\mathbf{x})=\sum\alpha_iy_iK+b\) from the model's own support vectors and matches it to 10 decimal places.

The pipeline

Y04

Why use a Pipeline?

It ties the scaler and the SVM together, so in cross-validation the scaler is re-fitted on each training fold and never sees the validation fold — that prevents data leakage.

Pipeline([("scaler", StandardScaler()),
          ("svm", SVC(kernel="rbf", C=100, gamma=10))])
pipeline
Y05

What is data leakage, and how did you avoid it?

Leakage is when information from the test data influences training; I fitted the scaler on training data only, tuned on training folds only, and touched the test set once at the end.

leakage
Y06

How did you make the 70/15/15 split?

Two calls to train_test_split with stratify and random_state=42: first 70/30, then the 30% halved into validation and test.

split
Y07

How does GridSearchCV work here?

It trains the pipeline for every \((C,\gamma)\) pair on each of 5 stratified folds, averages the accuracy, picks the best pair, and refits on all training data.

GridSearchCV(pipe, {"svm__C": [...], "svm__gamma": [...]},
             cv=StratifiedKFold(5, shuffle=True, random_state=42),
             scoring="accuracy", n_jobs=-1)

The double underscore in svm__C means "the C parameter of the step named svm".

gridsearch
Y08

Where is the one-vs-one voting in your code?

Inside SVC — it always trains one-vs-one for multi-class; decision_function_shape="ovr" only reshapes the output to one score per class.

multiclass
Y09

How did you get probabilities for the ROC curves?

SVC(probability=True), which runs Platt scaling with internal 5-fold cross-validation; it is deprecated in scikit-learn 1.9, where CalibratedClassifierCV is the recommended replacement.

Measurement and reproducibility

Y10

How did you measure latency?

With time.perf_counter() around model.predict() for one reading at a time, 500 times, after one warm-up call; I report mean, median, 95th percentile and maximum.

One reading at a time is deliberate: a live sensor delivers readings one by one, so batch timing (0.21 ms per reading) would flatter the system.

latency
Y11

How do you make the results reproducible?

A fixed seed (42) for splitting, cross-validation and probability fitting, stated library versions, and all numbers written to a results.json file by the script.

reproducibility
Y12

How did you code the time-ordered split?

Rows in the CSV are already in time order within each class, so for each class I took the first 70% of its row indices for training and the rest for testing.

for c in range(4):
    idx = np.where(y == c)[0]
    cut = int(0.7 * len(idx))
    tr += list(idx[:cut]); te += list(idx[cut:])

Y13

How would you put this model on a microcontroller?

Export the support vectors, the \(\alpha_iy_i\) coefficients, the six biases and the 14 scaling constants, then compute \(f(\mathbf{x})=\sum\alpha_iy_iK(\mathbf{x}_i,\mathbf{x})+b\) and the votes in C — about 50 KB of numbers.

Tools such as micromlgen or emlearn can generate that C code automatically.

deployment
Y14

Could this be done in Octave or MATLAB?

Yes — MATLAB's fitcsvm and fitcecoc, or LIBSVM's own Octave interface, provide the same SVM; I used Python because scikit-learn's pipelines and grid search make leakage-free tuning simple.
